# Nauta AI Skills

Personal AI skills repository for business discovery, market research, validation, finance, automation, sales, and research.

## Business OS v1

Included skills:

1. `opportunity-scout` — finds and ranks monetizable opportunities.
2. `market-research` — performs decision-oriented market research.
3. `business-validator` — attempts to disprove the thesis before capital/time is committed.

## Design principles

- Evidence before ideas.
- Current-market claims require current sources.
- Facts, estimates, and assumptions must be separated.
- No revenue or profitability promises.
- Prefer cheap validation tests before building.
- Optimize for founder fit, speed to revenue, margin, and acquisition feasibility.

## Recommended workflow

`opportunity-scout` -> shortlist -> `market-research` -> evidence pack -> `business-validator` -> GO / TEST / NO-GO.
